## Favorite Labs from CPSC 120

*Lab 2 - Mad Libs

    My favorite Lab was Lab 2, as the repetition in the code made it easy to practice and get a better idea of the difference between std::cout and std::cin. Input and output. My classmate and I were able to switch easily and we both had turns to code. The code was easy to understand and test. If there was an error in the code, we were able to pinpoint exactly what went wrong, and it usually was something to do with syntax or format. Looking back on the code now, I am able to recreate this easily. I really enjoyed being able to run the code and plug in our MadLibs words. It was fun.

*Lab 7 -Parking Functions

    Lab 7 parking_functions.cc was enjoyable. I struggled with executing the code, but my partner was able to take my ideas of the concepts and write the code. The repeating lines of code using bools and if-statements meant that I could familiarize myself with both of those things in different conditions, ie “time of day and weekday”. I enjoyed being both the navigator and driver, as the assignment directions were very direct. It was also nice being able to use the arithmetic operators in the conditional statements.

*Lab 11 Part 2

    I enjoyed Lab 11 since both parts of the assignments were similar to each other in terms of classes. It helped to understand why the Public and public_ were so different. I was the driver for Part 2, the hilo_functions.cc, and despite not being in class to do it, I learned a lot. The bools were understandable this time around, in that I realized that the bools would ask only “true/false” questions. It made my code a lot simpler since I did not have to worry about implementing complex code, as I only really needed one line. Originally I thought I needed to implement i-- but when I looked at the header file I realized how all the information worked together and built upon each other. It made understanding the need to set values and call the proper functions.
