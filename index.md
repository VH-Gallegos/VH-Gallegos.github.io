## Favorite Labs from 120

Lab 2 - Mad Libs
My favorite Lab was Lab 2, as the repetition in the code made it easy to practice and get a better idea of the difference between std::cout and std::cin. My classmate and I were able to switch easily and we both had turns to code. The code was easy to understand and test. If there was an error in the code, we were able to pinpoint exactly what went wrong. Looking back on the code now, I am able to recreate this easily. I really enjoyed being able to run the code and plug in our MadLibs words. It was fun.

Lab 7 -Parking Functions
Lab 7 parking_functions.cc was enjoyable. I struggled with executing the code, but my partner was able to take my ideas of the concepts and write the code. The repeating lines of code using bools and if-statements meant that I could familiarize myself with both of those things in different conditions, ie “time of day and weekday”. I enjoyed being both the navigator and driver, as the assignment directions were very direct. It was also nice being able to use the arithmetic operators in the conditional statements.

Lab 11 Hilo Game
I enjoyed Lab 11 since both parts of the assignments were similar to each other in terms of classes. I was the driver for Part 2, the hilo_functions.cc, and despite not being in class to do it, I learned a lot. The bools were understandable this time around, in that I realized that the bools would ask only “true/false” questions. It made my code a lot simpler since I did not have to worry about implementing complex code, as I only really needed one line.
